# Rui Sousa - Portfolio

Personal portfolio showcasing 17 shipped iOS apps and freelance services.

## Deploy

**Vercel:**
```bash
vercel deploy --prod
```

**Any static host:**
Just upload `index.html` - no build step, no dependencies.

- Zero frameworks

- Mobile responsive
